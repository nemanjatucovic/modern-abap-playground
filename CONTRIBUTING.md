# Contributing

This is a personal portfolio and learning repository, but constructive suggestions are welcome.

When proposing changes:

1. Keep examples generic and self-contained.
2. Do not include proprietary SAP/customer source code, real customer data, credentials, or internal URLs.
3. Prefer small, focused changes with clear commit messages.
4. Document the business scenario and technical concept demonstrated by the example.
5. Add or update tests when the example contains executable business logic.

The repository prioritizes readable examples that can be discussed in technical interviews and code reviews.
